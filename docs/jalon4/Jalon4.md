# Quatrième jalon à respecter : 18 mai

Pour cette date, chaque groupe doit avoir :

- **Un pipeline complet permettant de passer d’une vidéo à un mouvement robot rejouable :**  
  Le programme doit pouvoir enchaîner automatiquement les différentes étapes du projet.

- **Une première interface permettant d’utiliser ce pipeline :**  
  Le système doit proposer une interface simple permettant de lancer le traitement et d’accéder au résultat.

- **Une sauvegarde propre des données produites :**  
  Les sorties produites doivent être enregistrées de manière claire et réutilisable.

- **Une gestion simple des principaux cas d’erreur :**  
  Le système doit réagir correctement en cas de défaillance.

- **Une démonstration fonctionnelle sur plusieurs vidéos de test.**
